# assets-src

Arquivos-fonte pesados que **não vão para o Git**.

Coloque aqui o modelo baixado do Sketchfab, descompactado em `assets-src/bombonera/`
(deve conter `scene.gltf`, `scene.bin` e a pasta `textures/`).

Depois rode `npm run model:optimize`. Instruções completas em [`docs/MODELO-3D.md`](../docs/MODELO-3D.md).
